Auto Guild Join

Uses UID/password accounts already saved in Account Manager. Only accounts you own or are authorized to manage should be used. This action sends guild join requests only; it does not start matches.

How it works

1. Add your existing game accounts in Account Manager.
2. Enter the target Guild ID and region.
3. Choose the account quantity, or press ALL Accounts.
4. The server sends a join request for each selected saved account and reports accepted/failed requests in Live Logs.

Start Glory is separate. Guild joining will not start gameplay automatically.
