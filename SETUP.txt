GUILD GLORY — PREMIUM WEB CONTROL

1. Install dependencies:
   pip install -r requirements.txt

2. Start the project:
   python app.py

3. Open the web dashboard:
   http://127.0.0.1:<PORT_SHOWN_IN_TERMINAL>
   For a hosted deployment, open your hosting provider's public URL.

GUILD DASHBOARD
- Select a Guild ID and region.
- Use Preview Guild to inspect basic guild information.
- Choose an account count (0 means ALL saved UID/password accounts), then press
  Start Glory to save the selected guild, send join requests for that selection,
  and start the existing worker workflow. The dashboard itself starts idle.
- Use Refresh Guild to request a fresh guild snapshot.
- The dashboard shows current glory, tracked bot contribution, member details,
  and next-level remaining glory when the guild API provides the required
  threshold fields.
- Guild live glory/member data refreshes in the background when valid account
  tokens are available to the game worker.

ACCOUNT MANAGER
- Add UID/password accounts or JWT tokens from the website.
- Adding an account saves it but does not start a gameplay worker while Glory is
  stopped. Workers start only after Start Glory is pressed.
- Use Auto Guild Join to send requests for saved UID/password accounts. Results
  are logged per UID in the website's Live Logs panel.
- Existing accounts are loaded from accounts.json.

WEBSITE CONTROL
- Account list, pause/resume, refresh, restart, delete, and logs are controlled
  from the website.
- Telegram bot control has been removed from this package.
- The suji.py file is included as the standalone NG SUJEET Auto Guild Joiner
  reference; the website uses the same Join API parameter contract.

IMPORTANT
- Only use accounts you own or are authorized to manage.
- Join requests are not the same as confirmed membership. Check the live member
  list or game response for confirmation.
- The "Bot Contributed" value is measured from the saved glory baseline when
  tracking starts. If no valid game token is available, live glory may remain
  unavailable until the worker logs in.
- Next-level remaining glory is shown only when the guild API supplies a
  next-level target/remaining field. The dashboard does not guess thresholds.
- Keep the dashboard private or protect it with authentication before public
  deployment. The existing API routes should not be exposed to untrusted users.


ANDROID / TERMUX
- Extract the ZIP, cd into the extracted project folder, then run:
  pip install -r requirements.txt
  python app.py
- Open http://127.0.0.1:<PORT_SHOWN_IN_TERMINAL> in the same phone's browser.
- Keep the Termux process running while using the dashboard.
- Runtime credential/cache JSON files are shipped empty; add your own authorized
  accounts again. Never expose this dashboard to the public internet.
